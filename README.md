# IMO UP Connect Summit

Landing page estática e responsiva inspirada na identidade visual fornecida, com conteúdo estruturado a partir de `https://imoup.pt`.

## Ficheiros

- `index.html` — página principal
- `styles.css` — estilos visuais
- `script.js` — menu mobile e FAQ accordion
- `termos-e-condicoes/index.html` — página de termos

## Como abrir

Basta abrir `index.html` no navegador.

## Observações

- O conteúdo foi reconstruído com base nas secções públicas do website e nos materiais visuais anexados.
- Os botões de contacto utilizam `mailto:` e `tel:` para funcionamento imediato.
